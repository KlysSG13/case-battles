# ⚔️ Кейс-баттлы — запуск за 5 команд

Всё выполняется в папке проекта (нужен установленный Node.js 20+).

| # | Команда | Что делает |
|---|---------|-----------|
| 1 | `npm install` | установить зависимости |
| 2 | `npm run db:seed` | загрузить в базу кейсы, домены и бейджи |
| 3 | `npm run dev` | запустить приложение: **http://localhost:3000** (работает даже без Telegram) |
| 4 | вписать в файл `.env` три строки | токен бота и адрес приложения — см. ниже |
| 5 | `npm run tg:webhook` | подключить бота: кнопка «Открыть Кейс-баттлы» и команды появятся в Telegram |

Внутри 5 режимов: классика, конструктор бизнеса, спасение, питч инвестору и дуэли
(против ИИ или друга по ссылке) с рейтингом и лигами.

## Что вписать в `.env` (шаг 4)

```
BOT_TOKEN="123456789:AA..."      ← токен: @BotFather → /newbot → скопировать
WEBAPP_URL="https://..."         ← публичный адрес приложения (например, туннель ngrok)
APP_SHORT_NAME="casegames"       ← short name: @BotFather → /newapp
```

## Если что-то не работает

- `npm run deploy-check` — проверит, что приложение, база, токен и webhook в порядке.
- Подробная документация (архитектура, PostgreSQL, деплой) — в [README.md](README.md).
